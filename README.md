Spider-Man: Brand New Day

A responsive movie landing page built with React and Tailwind CSS.

Features

Responsive Navbar
Cinematic Hero section
Movie information section
Cast section with reusable components
Embedded trailer
Responsive design
Smooth section navigation
Book Now integration

Tech Stack

React
JavaScript
Tailwind CSS
Vite
Git & GitHub
Vercel

Run Locally

git clone https://github.com/tanishqkale91-cmd/spiderman-landing/edit/main/README.md
cd spiderman-landing
npm install
npm run dev
